# 云端备份专家 (CloudSync Pro)

为思源笔记打造的高性能第三方云端存储备份与快照管理插件。

## ✨ 核心特性

- 🚀 **全面支持 S3 对象存储**：MinIO、Cloudflare R2、AWS S3、阿里云 OSS、腾讯云 COS、华为云 OBS 等兼容协议。
- 📁 **全面支持 WebDAV**：坚果云、Nextcloud、群晖 Synology WebDAV、AList 等。
- 📦 **多种备份模式**：支持全量工作空间快照、单笔记本独立备份、以及 Markdown 归档导出。
- 🔐 **AES-256 端到端加密**：客户端本地强加密，云端服务商无法破解。
- ⏰ **智能自动备份计划**：支持设定定时自动备份周期，静默守护笔记数据。
- ♻️ **生命周期保留策略**：自动清理旧版本备份，防止云存储超额。
- 🌐 **可视化云端快照浏览器**：在思源内直接查看云端所有历史版本，支持一键下载还原。
