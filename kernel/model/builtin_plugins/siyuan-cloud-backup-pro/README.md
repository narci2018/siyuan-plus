# CloudSync Pro for SiYuan

Professional third-party cloud backup and snapshot management plugin for SiYuan Note.

## Features

- Native S3 object storage (MinIO, Cloudflare R2, AWS S3, Aliyun OSS, Tencent COS).
- Native WebDAV protocol (Jianguoyun, Nextcloud, Synology WebDAV, AList).
- Multiple backup modes (Full workspace snapshot, Per-notebook backup, Markdown export).
- Client-side AES-256-GCM zero-knowledge encryption.
- Automated scheduled backups & backup retention lifecycle.
- Visual cloud snapshot browser and one-click restore.
